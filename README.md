# Sila — صِلة 💚

**Connecting people. Opening possibilities.**

Sila is an independently developed, Syria-inspired, globally minded fintech **concept**. This repository currently contains a polished bilingual, responsive frontend prototype.

## Try it

Open `index.html` in your browser or publish the static site with GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Features

- Arabic (RTL) and English language switching
- Responsive landing page and mock wallet dashboard
- Simulated send-money and request-money interactions
- Client-side transaction activity and demo wallet balance
- Local browser storage for simulated transactions
- No dependencies or build step

## Important: not real payments

**All data and transactions are simulated.** This prototype does not authenticate users, hold deposits, send funds, process payments, connect to banks, or contact payment networks. Local storage is only for demo preferences and simulated activity; it is **not** appropriate for real balances or sensitive financial data.

A production financial service needs a licensed operational/payment partner or relevant authorization, country-specific eligibility and sanctions review, compliant onboarding (KYC/AML), secure server-side double-entry ledger, authenticated APIs, audit trails, reconciliation, fraud monitoring, privacy/security reviews, and specialist legal advice before any real-money features are offered.

## Roadmap

1. Validate user needs, payment corridors, eligibility, regulations, and potential partners.
2. Design accessible onboarding and real UX workflows with privacy by design.
3. Implement secure application architecture and tested ledger in a sandbox.
4. Integrate licensed payment partners only after legal and technical approval.

Deep emerald green, clean white, subtle gold accents, Arabic-first identity with a global feel.
